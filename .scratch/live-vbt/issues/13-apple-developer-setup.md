# Apple developer setup and installing on the XRs

Type: task
Status: open
Blocked by:

## Question

Get the Station app installable on the XRs using the user's personal Apple Developer account.

Checklist for the user:

- Confirm the membership is paid. Apps installed with a free account stop working after 7 days.
- Register each XR (and the 17 Pro) as a development device.
- Choose the bundle ID.
- Choose the install route: directly from Xcode, or TestFlight internal testing.
- Turn on Developer Mode on each phone.

Output: the bundle ID, the registered device list, and the chosen install route.
