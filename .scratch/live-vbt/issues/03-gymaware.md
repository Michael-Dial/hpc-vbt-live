# GymAware definitions, export, and alignment

Type: research
Status: open
Blocked by:

## Question

How does GymAware, the Criterion, define and compute its outputs, and how can its data be exported and aligned in time with Station Recordings?

Cover:

- How it detects the start and end of a rep, including concentric onset and end thresholds.
- How it defines MCV, MPV, peak velocity, displacement or ROM, and power.
- Its sampling rate and filtering.
- How it handles horizontal bar movement and tether angle.
- Export options: CSV, cloud API, per-sample versus per-rep data, and the timestamps and clock source each one carries.
- Options for time alignment with a phone Recording: matching by rep index, wall-clock sync, or a shared event visible to both systems (for example, a deliberate bar tap at the start of each Set).
- Published validity of GymAware against 3D motion capture, so the Criterion's own error is known before the validation pass criteria are set.

Confirm with the user which GymAware model and software version the lab has.

Output: the definitions, the recommended export path, and a recommended alignment method.
