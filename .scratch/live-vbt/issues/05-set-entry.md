# Set entry at the Station

Type: grilling
Status: open
Blocked by:

## Question

Already decided: a Session is one block of gym time, each Station makes one Recording per Session, and each Set carries its Participant, load, Station, and start and end time within that Recording. Participants may rotate through a Station.

Still open: how are a Set's Participant and load entered, and how are Set boundaries marked?

Decide:

- Where Participant and load are entered: on the iPad (Host UI), on the Station phone, or either.
- How a Participant is picked quickly when several rotate through one Station.
- Set boundaries: manual start and stop, automatic from bar motion, or automatic with confirmation.
- What happens to Reps detected while no Set is open.
- Phase 1 constraint: a Station must work fully without a Host, so the Phase 1 entry path can't depend on the iPad.
