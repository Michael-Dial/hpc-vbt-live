# Reference Dataset collection

Type: task
Status: open
Blocked by: 03, 04

## Question

Collect the Reference Dataset: Station Recordings (full-rate video plus per-frame timestamps) paired with GymAware data, under the lab's existing IRB.

The agent drafts the collection protocol and checklist; the user runs the Session. The protocol covers:

- 5–10 Participants.
- All four lifts across a range of loads.
- Deliberately messy Reps: unracking and reracking, pauses, partial Reps, bar wobble, and dead-stop versus touch-and-go deadlifts.
- The alignment event chosen in "GymAware definitions, export, and alignment", performed for every Set.
- File naming, and storage on a local machine only. Never commit the data to git or upload it to any cloud service.

Output: the dataset's location, an inventory (Participants, Sets, Reps per lift and load), and known issues.
