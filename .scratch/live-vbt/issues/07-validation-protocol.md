# Validation protocol and pass criteria

Type: grilling
Status: open
Blocked by: 03, 06

## Question

What protocol and pass criteria will v1 be validated against GymAware with, under the lab's existing IRB?

Decide:

- Outcomes: MCV, MPV, peak velocity, ROM, rep detection (precision, recall, F1), and feedback latency.
- Analysis: repeated-measures Bland-Altman limits of agreement, CCC, MAE/RMSE, proportional bias, and TOST against an a priori SESOI.
- How the SESOI is derived, for example from GymAware's own typical error or from a practically meaningful change in velocity.
- Lifts, load range (for example 20–100% 1RM), Participant N, and Reps per load.
- Which camera placement variations to include.
- A pass threshold for each outcome.
- Whether a 3D motion capture subset is included.

Running the study itself is outside this map.
